# ديوان الشعر العربي — مستودع البناء والنشر

هذا مستودع **مصدر البناء** لموقع الإصدارات الساكنة: قوالب Hugo، وسكربتات خط الأنابيب، وملف نشر GitHub Pages من أصل إصدار (Release)، وخدمة بحث D1 الإنتاجية.

- الموقع المنشور: `https://smsmy.github.io/poetry-site/`
- طريقة النشر: **أصل مسبق البناء** — بدون بناء Hugo داخل CI، وزمن النشر 2 إلى 3 دقائق.
- أرقام مرجعية: الموقع النهائي 788.3 ميجابايت خامًا، الأرشيف 343.8 ميجابايت، فهرس العناوين 18.1 ميجابايت.

## 1. بنية المستودع

```
hugo.toml                إعداد Hugo، والمسار الأساس مضبوط على مسار المشروع الفرعي
layouts/                 قوالب Hugo: الأساس، شجرة القصيدة، شجرة الشاعر، شجرة العصر
static/css, static/js    الأصول الثابتة (بحث.js يدعم Pagefind ومسار D1 أيضًا)
scripts/                 سكربتات خط الأنابيب (مفصلة أدناه)
worker/index.mjs         خدمة البحث الإنتاجية على D1 (للقراءة فقط، ومحدد CORS ثابت)
.github/workflows/       ملف النشر من أصل Release
```

سكربتات `scripts/`:
- `build_static.py`: توليد محتوى Hugo من المصادر المحلية (يعمل على جهاز البناء فقط).
- `compact_static.py`: تفريغ أجزاء الصفحات غير المفهرسة وتقسيم خريطة الموقع.
- `minify_final.py`: مرحلة التفريغ النهائية (يحافظ على وسوم الإغلاق).
- `normalize_catalog_v2.py`: إضافة التوائم المطبَّعة لعناوين الشعراء (شاملة وقابلة للتكرار).
- `generate_title_chunks.py`: توليد 68 ملفًا للعناوين، كل 2000 معرف في ملف.
- `rewrite_base_url.py`: تصحيح الروابط المطلقة في شجرة مبنية سابقًا (لتحضير حزم الإصدار).
- `archive_final.py`: إنشاء الملف الأرشيفي النهائي.

ما لا يُتتبَّع حسب ملف `.gitignore`: محتوى التوليد، أشجار الأبنية `public*`، الأرشيفات، قاعدة البيانات المحلية `reconstruction.sqlite`، مجلدات البيانات الخام، أي تقرير قد يحمل بيانات دخول، وملف `config.php` وما يشبهه من ملفات الأسرار.

## 2. البناء المحلي

يُنفَّذ من مجلد المشروع القديم `poetry-static` لأنه يحوي البيانات المحلية كاملة:

```powershell
hugo --minify --destination public-optimized
python compact_static.py --site public-optimized
python scripts/minify_final.py
python normalize_catalog_v2.py --site public-final
python scripts/generate_title_chunks.py --mode raw
npx --yes pagefind@1.5.2 --site public-final --glob "**/poet/*.html" --output-subdir pagefind-catalog
python scripts/archive_final.py
```

تحذير حرج: خيار `--glob "**/poet/*.html"` **إلزامي** مع Pagefind؛ بدون تقييده سيفهرس كل صفحات القصائد (134 ألف صفحة) وسينتج فهرسًا بحجم 477 ميجابايت — وقد حدث فعليًا في تجربة داخلية.

للتحضير لحزمة نشر من شجرة مبنية بمسار قديم، استعمل `rewrite_base_url.py` على نسخة من الشجرة؛ أما البناء الجديد فيأتي مضبوطًا تلقائيًا لأن `hugo.toml` في هذا المستودع يشير إلى `https://smsmy.github.io/poetry-site/`.

## 3. النشر عبر Release

1. أنشئ إصدارًا (Release) بوسم مثل `site-v1`.
2. ارفع للإصدار الأصل باسمه الحرفي: `public-final.tar.gz`.
3. شغّل الواجهة Actions بعنوان «Deploy Pages (release artifact)»، أدخل رقم الوسم **وSHA-256 للأصل** في الحقل `expected_sha256` (يُرفض النشر عند عدم التطابق).
4. خطوات الواجهة: تنزيل الأصل، تحقق الـSHA-256، فك الضغط إلى مجلد `site`، رفع الأصل الوسيط، ثم النشر.
5. زر إعداد يدوي واحد بعد أول تنشيط: Settings → Pages → Source = GitHub Actions.

السقوف: الموقع الخام 788.3MB أقل من سقف صفحات GitHub بفارق مريح (1GB)؛ والأرشيف 343.8MB يُنزَّل سريعًا.

## 4. خدمة البحث D1 الإنتاج

- الملف `worker/index.mjs` — **للقراءة فقط**؛ لا يحوي أي مسار كتابة أو استيراد.
- السماح لاصل وحيد: `https://smsmy.github.io` عبر رؤوس CORS.
- الحدود المفروضة: 80 حرفًا للاستعلام، 8 كلمات كحد أقصى، 24 حرفًا للكلمة الواحدة.
- مسار القياس محذوف من الإنتاج (متاح فقط في نسخة التطوير داخل مشروع البحث).
- النشر يتم بعد موافقتك من مجلد `worker/` مباشرة: `npx wrangler deploy` (المعرف مرتبط في `worker/wrangler.toml` مع قاعدة D1 `poetry-norm-contentless`، وبلا أي أسرار في الملف).
- عناوين النتائج يجلبها العميل من ملفات `/search-title/` (68 مقطعًا بالتشكيل؛ بلا قراءة D1 إضافية).
- الاستيراد على القاعدة البعيدة يتم عبر Worker مؤقت يُنشر ويُستخدم ثم **يُحذف نهائيًا**.

أمر التحقق من حذف Worker المؤقت بعد انتهاء الاستيراد:

```powershell
npx wrangler deployments list --name poetry-d1-importer
```

النتيجة المتوقعة: خطأ يقول أن الاسم غير موجود (worker_not_found) — وهذا دليل الحذف.

## 5. ضبط الجودة

- مطابقة المعرّفات: النموذج المحلي 134,478 صفًا يطابق D1 المحلي تقاطعًا كاملًا.
- القاعدة البعيدة تُستكمال بعد افتتاح حصة الكتابة اليومية (100 ألف كتابة/يوم).
- تقريرات القياس وتفريغات الاختبار تبقى في مشروع البحث المحلي ولا تُرفع إلى هذا المستودع.
